# 通讯录管理系统（C++）

一个基于 C++ 结构体数组实现的控制台通讯录管理程序，课程练习项目。

## 功能

- [x] 添加联系人（姓名、性别、年龄、电话、地址）
- [x] 显示所有联系人
- [x] 按姓名删除联系人
- [x] 查找联系人
- [x] 修改联系人
- [x] 清空通讯录

## 开发环境

- IDE：Visual Studio 2022
- 编译器：MSVC (v145)
- 标准：C++20
- 最大联系人数量：1000

## 运行方式

1. 用 Visual Studio 打开 `Project1.slnx`
2. 按 `Ctrl + F5`（开始执行，不调试）

## 中文乱码说明

- 源文件保存为 **UTF-8 with BOM**
- 项目编译选项已加 `/utf-8`
- 程序启动时调用 `SetConsoleOutputCP(CP_UTF8)` 将控制台切换为 UTF-8 显示

## 技术要点

- 使用结构体 `person` 描述联系人，`Addessbooks` 管理联系人数组
- 查找联系人通过遍历数组匹配姓名，删除时将后续元素前移覆盖
- 菜单循环采用 `while(true)` + `switch` 分发
